## Ceannasai
Command units to win small battles. 

Spears beat Cavalry, Cavalry beat Archers and Archers beat Spears. (Wizards beat them all)

This is just a proof of concept. I would like to expand it with features such as:
* A campaign mode with story and character development.
* Terrain ( slowing down or blocking units )
* More types of magic (fire, poison, mind control, necromancy...)
* Other armies (undead, elves, dwarves...)
* Battle objectives ( capture, defend...)


### Controls
Mouse controls.

Hot keys:
On mac, use the 'Meta' key while a unit is selected to rotate the unit.


### About
Made using Go and ebiten.
